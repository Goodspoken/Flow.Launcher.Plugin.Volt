# Volt ⚡

[English](#english) | [Русский](#русский)

---

## English

**Volt** is a lightweight plugin for [Flow Launcher](https://www.flowlauncher.com/) that allows you to instantly switch between Windows power plans.

![Volt Icon](Images/app.png)

### Features

- 🚀 **Fast:** Switch power plans with a single command without opening the Control Panel (0ms lag thanks to direct registry and Win32 API calls).
- ⚡ **Up to 4 Modes:** Support for standard Windows power schemes (Balanced, High Performance, Power Saver, and **Ultimate Performance**).
- 🎨 **Visual UI:** Colored status icons for each power mode showing whether it is active.
- 🔌 **Status Display:** Subtitles show connection type, charging state, and battery percentage (e.g. `[⚡ Charging 72%] | Active` or `[🔋 Battery 45%] | Select`).
- 🛠️ **System Shortcut:** Quickly open Windows Power & Sleep settings from Flow Launcher results.

### Usage

1. Open Flow Launcher (usually `Alt + Space`).
2. Type the keyword `volt`.
3. Select your desired power plan and press `Enter`.

### Installation & Update

#### Via Plugin Store (Recommended)
Open Flow Launcher and search for Volt in the store or run:
`pm install Volt` or `pm update Volt`

#### Manual Installation
1. Download the latest release `Volt-v1.2.9.zip` from the [Releases](https://github.com/Goodspoken/Flow.Launcher.Plugin.Volt/releases) section.
2. Extract the archive into your Flow Launcher plugins folder:
   `%APPDATA%\FlowLauncher\Plugins\Volt`
3. Restart Flow Launcher.

## Русский

**Volt** — это легковесный плагин для [Flow Launcher](https://www.flowlauncher.com/), позволяющий мгновенно переключаться между схемами управления электропитанием Windows.

### Возможности

- 🚀 **Быстрота:** Переключение планов электропитания одной командой без необходимости открывать Панель управления (задержка 0 мс благодаря использованию Win32 API и прямому чтению реестра).
- ⚡ **До 4 режимов:** Поддержка стандартных схем питания Windows (Сбалансированный, Высокая производительность, Экономия энергии, а также **Максимальная производительность**).
- 🎨 **Интуитивный UI:** Цветные иконки статуса для каждого режима, наглядно показывающие текущую активную схему.
- 🔌 **Информативность:** В описании отображается тип подключения к сети, статус зарядки батареи и процент заряда (например, `[⚡ Зарядка 72%] | Активен` или `[🔋 Батарея 45%] | Выбрать`).
- 🛠️ **Системный ярлык:** Быстрый доступ к системным настройкам питания Windows напрямую из результатов поиска.

### Использование

1. Откройте Flow Launcher (обычно `Alt + Space`).
2. Введите ключевое слово `volt`.
3. Выберите нужную схему питания и нажмите `Enter`.

### Установка и обновление

#### Через Магазин плагинов (Рекомендуется)
Откройте настройки Flow Launcher, найдите Volt в магазине или выполните команду:
`pm install Volt` или `pm update Volt`

#### Ручная установка
1. Скачайте последнюю версию `Volt-v1.2.9.zip` из раздела [Releases](https://github.com/Goodspoken/Flow.Launcher.Plugin.Volt/releases).
2. Распакуйте архив в папку плагинов Flow Launcher:
   `%APPDATA%\FlowLauncher\Plugins\Volt`
3. Перезапустите Flow Launcher.
